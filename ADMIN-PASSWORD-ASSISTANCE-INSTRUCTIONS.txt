WAYNE LOGS - ADMIN PASSWORD ASSISTANCE

SECURE BEHAVIOUR
- Admin searches for a customer using the exact registered email.
- Existing customer passwords are never visible because they are stored as irreversible hashes.
- Admin confirms their own password before creating a temporary password.
- The temporary password appears once in the Admin panel.
- Creating it immediately logs the customer out on every device.
- The first successful login consumes the temporary password permanently.
- The customer is immediately sent to Create Private Password.
- All store, wallet, order and profile API access is blocked until that change is completed.
- The new private password is never shown to the administrator.
- Issuing a temporary password is recorded in the Audit Log without storing either password.

DEPLOY IN 3 STEPS
1. Replace all project files with this update. Keep your private server .env.
2. Run git add -A, git commit -m "Add one-use admin password assistance", then git push.
3. Wait for Render and Vercel. Open Admin > Password Help and test with a customer account you control.

TEST
1. Search the test customer's email and generate a temporary password.
2. Login as that customer using the temporary password. The mandatory password page must open immediately.
3. Create a private password. Confirm the temporary password no longer works and the new password does.
