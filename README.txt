WAYNE LOGS — FRESH BUILD
=========================

This is a completely new project. It does not replace or depend on your older WAYNE LOGS files.

FILES
-----
index.html   - storefront
admin.html   - admin dashboard
styles.css   - all design
app.js       - store/cart/checkout logic
admin.js     - admin product/order logic

RUN
---
1. Extract the ZIP.
2. Open the NEW folder in VS Code.
3. Open index.html with Live Server, or deploy the folder as a static site.

ADMIN
-----
Open admin.html.

The admin panel includes:
- Overview
- Product management
- Order management
- Platform list
- Settings/reset

IMPORTANT
---------
This project is HTML + CSS + JavaScript only.
Product/order data uses browser localStorage.

For real production use across multiple devices, secure admin authentication,
real payment verification, databases, private fulfillment, and customer accounts
must be implemented on a backend. Do not put payment secret keys in JavaScript.

The storefront is designed for legitimate social-media digital services/assets
you are authorized to sell and VPN subscriptions/licenses. Do not use it to
sell stolen passwords, session cookies, authentication tokens, or compromised accounts.
