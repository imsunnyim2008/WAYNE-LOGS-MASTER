WAYNE LOGS ADMIN PASSWORD RECOVERY

This script updates only the existing account matching ADMIN_EMAIL. It keeps the
same user ID, orders, wallet transactions, products and customers.

1. Deploy this update.
2. In Render Environment, confirm ADMIN_EMAIL is the existing admin email.
3. Temporarily add ADMIN_RESET_PASSWORD with a new password of 12+ characters.
4. Open Render Shell for the backend and run: npm run reset:admin
5. Wait for: Admin password reset completed
6. Immediately delete ADMIN_RESET_PASSWORD from Render Environment.
7. Sign in with ADMIN_EMAIL and the new password.

Never commit the password to GitHub and never send it in chat or screenshots.
